# LaCasa Real System v4

تحديثات النسخة دي:
- تعديل أسعار الأجهزة من صفحة الأجهزة.
- اسم العميل بقى اختياري عند بداية الجلسة.
- إضافة خصم على الفواتير والأوردرات.
- ربط الفاتورة بعميل موجود.
- إمكانية إضافة الفاتورة على حساب العميل بدل الكاش.
- صفحة العملاء فيها تعديل الحساب.
- التقارير بتفصل بين الكاش والديون.

## التشغيل
npm install
npm start

افتح:
http://localhost:3000
